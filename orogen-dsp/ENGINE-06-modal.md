# Движок 06 — Modal

Модальный синтез: удар возбуждает банк из 12 резонаторов второго порядка.
Спектр **ингармонический** — этого не получить ни вычитающим синтезом, ни FM.

```
make build/test_modal && ./build/test_modal
```

## Замеры

| проверка | результат |
|---|---|
| алиасинг (энергия выше 0.44·fs), ноты 45/57/69/81 | −92.9 / −93.1 / −94.0 / −93.5 дБ |
| DC | 0.268·10⁻³ |
| RMS / разброс между материалами | 0.216 / 4.2 дБ |
| число мод: яркость 0 → 1 | 2 → 12 (нота 45), 2 → 10 (69), 2 → 4 (93) |
| T60: задано 2.60 / 6.12 / 10.82 с | измерено 2.44 / 5.07 / 8.00 с |
| стабильность 10 с при T60 = 12 с | пик 1.57, NaN/переполнения нет |
| CPU | 6.4 % ядра на 16 голосов = 0.40 %/голос |

Офлайн-демо: `audio/modal_demo.wav` — 20 с, 4 материала (колокол → стекло → дерево →
сталь/камень), пик 0.890, RMS 0.127, DC −2·10⁻⁵.

## Резонатор

```
r    = 10^(−3/(T60·fs))         амплитуда падает на 60 дБ за T60
a1   = 2·r·cos(ω), a2 = −r²
y[n] = x[n] + a1·y[n−1] + a2·y[n−2]
```

Импульсный отклик: `h[n] = rⁿ·sin((n+1)ω)/sin(ω)`, пик ≈ `1/sin(ω)`.

## Пять решений, каждое из замера

### 1. Мода выше Найквиста не создаётся

`if (f0·ratio ≥ 0.45·fs) break` — не «заглушить», а не создавать вообще.
Резонатор выше Найквиста не звучит тише: он **заворачивается** в слышимую полосу
и даёт дребезг. На ноте 93 из 12 мод остаётся 4 — это правильно, так ведёт себя
реальное тело.

### 2. Нормировка мод: sin(ω), а не 1/sin(ω)

Первая версия компенсировала «наоборот» — умножала на 1/sin(ω), считая, что
низкие моды тише. Замер показал **разброс 16.4 дБ по нотам** (RMS 0.43 на ноте 45
против 0.066 на ноте 81). Причина: пик импульсного отклика уже равен 1/sin(ω),
то есть низкие моды изначально громче. Правильно — умножать на sin(ω):
разброс упал до 4.2 дБ.

### 3. Нормировка на сумму амплитуд, а не на sqrt(N)

В момент удара все моды стартуют **синфазно** (их возбуждает один импульс),
поэтому пик атаки — сумма амплитуд. Даёт равную громкость материалов с разной
плотностью мод: у стали 12 мод в полосе 1…4.35 (плотный удар), у дерева — до 62-й
гармоники.

### 4. Жёсткого клиппинга на выходе нет

Первая версия зажимала выход в ±4.0 — и это давало «алиасинг −28 дБ», которого
не было: клиппинг сам является нелинейностью, порождающей широкий спектр.
Убран клиппинг — алиасинг −93 дБ.

### 5. HP 20 Гц, а не 0.5 Гц

Импульсное возбуждение даёт DC-составляющую. С фильтром 0.5 Гц она оставалась
в резонаторах секундами и съедала динамический диапазон (DC 78·10⁻³ при RMS 4.0).
20 Гц: DC 0.268·10⁻³ при RMS 0.216.

## Что осталось за рамками

- Нет связи резонаторов (в реальном теле моды связаны, и удар даёт «перекачку» энергии).
- Возбуждение — только шумовой burst; нет вариантов «щипок/трение/смычок».
- Таблицы мод фиксированы; в Terrain материал описывается кривой затухания и «морфом».
- Демо-баг (не движка): голоса, переиспользованные после паузы, «умирали» на первом
  сэмпле, потому что счётчик тишины не сбрасывался при спавне. Исправлено.
