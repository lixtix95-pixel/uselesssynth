# OROGEN DSP — движки синтеза, по одному до конца

Чистое C++17-ядро без JUCE: движки, контент, тесты и офлайн-рендер компилируются
и проверяются независимо от плагин-обёртки. Каждый движок доводится до состояния
«проходит 11 проверок» (см. `ENGINE-01-wavetable.md`), а не «звучит».

## Сборка и запуск

```bash
# VST3-обёртка (JUCE 8) лежит рядом: ../orogen-plugin, см. PLUGIN.md
make test     # 16 наборов: движки, вокальные источники/Granular, инструмент/метры и FX
make asan-granular  # границы Granular под ASan/UBSan; GCC/Clang
make asan-streams   # независимые потоки направлений под ASan/UBSan
make asan-meters    # метры и полифония под ASan/UBSan
make tsan-meters    # гонка аудиопотока/GUI под TSan (Linux/GCC, отдельно от ASan)
make asan-delay     # отдельная автоматизация Delay под ASan/UBSan; GCC/Clang
make demo     # 11 офлайн-рендеров в audio/*.wav + спектрограммы
make build/render_demo_fx && ./build/render_demo_fx       # audio/fx_demo.wav (34 с)
make build/render_demo_comb && ./build/render_demo_comb   # audio/comb_chorus_demo.wav (24 с)
```

Требуется g++ ≥ 10 (C++17) и GNU make. Никаких внешних зависимостей.
Последний полный прогон 31.10.2026: 16/16 наборов, **383 OK / 0 FAIL**.
Сюда входят 13 проверок ограниченного вибрато в источниках Choir/Vox и на
выходе Granular; подробные данные и ограничения headroom — в `ENGINE-05-granular.md`.
Метры публикуют пики окнами 10 мс через атомики, с экспоненциальным спадом
120 мс; TSan до исправления обнаружил гонку чтения/записи, после — 0 отчётов
в проверенном сценарии. ASan/UBSan потоков Reverse и метров прошли отдельно.
ASan/UBSan Granular: 240 сценариев / 3013 зёрен с автоматизацией, 432 / 3114
с вероятностями реверса 0/50/100%, 216 / 2016 на границе 10 мс и 30 быстрых +
96 медленных зёрен длинного источника, без ошибок. Отдельный ASan/UBSan Delay: три sample rate,
18 с автоматизации, без ошибок.
Старый `make test`
мог скрыть код ошибки из-за `| tail`; теперь код ненулевого завершения сохраняется
и дальнейшие тесты не запускаются. Данные и ограничения текущего Granular —
`ENGINE-05-granular.md`; список ниже частично сохраняет исторические замеры.

## Инструмент (этап после движков)

Восемь движков собраны в один инструмент: 8 слотов A–H, полифония 16 голосов,
режимы Stack / Morph / Split, мастер-цепочка из 12 эффектов (drive на 19 моделях,
COMB на 2 моделях, chorus ×2, ping-pong delay, reverb, plate, EQ, material,
spectre, glitch, компрессор, лимитер). Подробности и замеры —
`INSTRUMENT.md`, демо — `audio/instrument_demo.wav` (40 с, 5 секций, все 8 движков).

```
make build/test_instrument && ./build/test_instrument   # 20 проверок
make build/render_demo_instrument && ./build/render_demo_instrument
```

Ключевые цифры: калибровка патчей 0.1 дБ, DC 3·10⁻⁵, полифония складывается ×1.5,
16 голосов × 8 слотов — 20 % ядра, 8 голосов × 3 слота — 29 %.

## Нагрузка (профиль и оптимизации)

## Ключевые инженерные решения (движок 1)

1. Таблицы синтезируются **из спектра** обратным FFT — band-limited по построению,
   а не «нарисовали и отфильтровали».
2. MIP-иерархия с шагом **треть октавы** (25 уровней) и выбор «самый яркий безопасный»,
   без кроссфейда с небезопасным уровнем.
3. Плотность таблицы **×8** от минимума + **кубическая** интерполяция: убирает образы
   интерполяции, которые иначе складываются в алиасинг.
4. Нелинейности (warp / fold) — **2×/4×/8×** с полуполосными КИХ (127 / 255 отсчётов),
   финальный срез 0.22 от 2×-Найквиста.
5. DC-блокер, анти-денормали, сглаживание 18–25 мс, детерминированный ГПСЧ, дрейф на голос.
