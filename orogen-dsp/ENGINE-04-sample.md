# Движок 04 — Sample

Воспроизведение one-shot'а как играбельного инструмента. Не «плеер на 20 строк»:
питч-шифт на 4 октавы вверх без алиасинга, точная временная шкала, петля без щелчков.

```
make build/test_sample && ./build/test_sample
```

## Контент

Нет ни одного внешнего файла: 8 источников синтезируются процедурно
(Fm Tine, Karplus Pluck, Choir Ah, Glass Hit, Tape Pad, Wood Knock, Vox Ah, Sub Bass),
у каждого — 5 MIP-уровней (1× … 16×). Итого 6.0 МБ, сборка 533 мс, формат `.orosmp`
(round-trip бит-в-бит).

| параметр | значение |
|---|---|
| корневая нота | A2 = 110 Гц |
| длительность источника | 2.0 с @ 48 кГц |
| MIP-уровни | 5 (1×, 2×, 4×, 8×, 16× вниз) |
| фильтр децимации | полуполосный КИХ 255 отвода, Кайзер β=8, срез 0.22·fs |
| интерполятор чтения | полифазный windowed-sinc, 32 отвода × 256 фаз |
| петля | кроссфейд 25 мс + квантование в целое число периодов |

## Замеры

| проверка | результат |

| алиасинг, ноты 45/57/69/81 | −91.1 / −86.8 / −76.6 / −74.8 дБ |
| алиасинг по питч-рейту (октавами) | 1× −91.1, 2× −86.7, 4× −76.6, 8× −74.5, 16× −67.7 дБ |

| RMS / разброс по контенту | 0.125 / 10.8 дБ (перкуссия выше по природе) |
| щелчок ручки | ×0.03 от естественного наклона |
| субнормали после `stop()` | нет |
| петля | 0 разрывов за 6 с (наклон 0.0858, аномалий 0) |
| Scan | RMS 0.1158 в начале → 0.0033 в хвосте |
| CPU | 5.1 % ядра на 16 голосов = 0.32 %/голос |

Офлайн-демо: `audio/sample_demo.wav` — 20 с, 4 фразы, 8 источников, пик 0.890,
RMS 0.118, DC 4·10⁻⁵, ни одного брошенного голоса из 48.

## Что пришлось исправить (и почему)

### 1. Шаг чтения в единицах MIP-уровня — фатальная ошибка

Позиция хранилась в шкале выбранного уровня, а шаг задавался в шкале оригинала.
Уровень прорежен в 2^L раз ⇒ сэмпл играл в 2^L раз быстрее и «звенел».
Теперь `pos` живёт в шкале исходника, а уровень — только выбор таблицы:
`pA = readPos · lenA/lenOrig`.

### 2. Масштаб из 2^L вместо фактических длин

Полуполосный фильтр добавляет задержку, длина уровня перестаёт быть ровно `len0/2^L`.
Расхождение 0.2 % = расстройка 2 Гц на 880 Гц: основной тон расползался по бинам,
и метрика честно видела «мусор». Масштаб теперь `lenA/lenOrig`.

### 3. Зацикленный one-shot — источник «дрожания» и ложного алиасинга

Затухающий one-shot в петле даёт пилообразную огибающую на частоте петли (≈4.5 Гц).
Её сайдбенды попадают в промежутки между гармониками: измерялось −10 дБ при
идеально чистом спектре. В Terrain 2 177 записи — все one-shot'ы, поэтому
**петля выключена по умолчанию** (`setLoop(true)` — опция), а конец гасится fade-out 256 отсчётов.

### 4. Петля не кратна периоду ⇒ расстройка на каждом обороте

Длина петли квантуется в целое число периодов корневой ноты (`N · sr/110`).
Стандартный приём сэмплеров; без него основной тон «размазывается» на ±6 бинов.

### 5. Catmull-Rom → windowed-sinc

При питче +3 октавы шаг чтения = 8 отсчётов. Проверка показала, что кубика здесь
ни при чём (шаг целый), но при дробных рейтах её образы (−27 дБ) заворачиваются
в полосу. Поставлен 32-отводный sinc с окном Кайзера и 256 фазами: образы < −80 дБ,
цена — 0.32 % CPU на голос вместо 0.21 %.

### 6. Метрика алиасинга для one-shot'ов: три ошибки подряд

1. **Без ФВЧ** энергия огибающей (0–20 Гц) считалась алиасингом: −7 дБ у чистого сэмпла.
   Добавлен ФВЧ 2×40 Гц перед FFT (в `tests/engine_suite.h`).
2. **Окно 16384 (341 мс) длиннее сэмпла**: при +3 октавы one-shot длится 250 мс, и обрыв
   сигнала внутри окна даёт широкополосную утечку −27 дБ. Правило: окно ≤ 70 %
   длительности сэмпла на данной ноте (`fftForNote()` в `tests/test_sample.cpp`).
   То же окно, уложенное внутрь активной части, даёт −74.5 дБ на той же ноте.
3. **Допуск гармоник 5 бинов слишком узкий** для окна 4096 (11.7 Гц/бин): расширен до 8 бинов.

## Что осталось за рамками

- Питч-шифт вниз ниже −1 октавы читается с уровня 0 без фильтрации: сэмпл удлиняется,
  спектр не страдает (это интерполяция, а не децимация).
- Нет ресемплинга при смене частоты проекта: банк строится под 48 кГц, для других SR
  пересобирается (`buildFactory(sr)`). В VST3 это делает фоновый поток.
- Нет velocity-слоёв и round-robin (в Terrain — по 2 177 записей на слот, здесь 8).
