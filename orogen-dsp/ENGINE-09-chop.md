# Движок 09 — CHOP (слайсер лупов)

Девятый движок и первый, который работает не с целым сэмплом, а с его куском:
луп режется по транзиентам, куски раскладываются по клавишам, каждый играется
целиком (или N раз, или в обратную сторону) и обрывается без щелчка.

```bash
make build/test_chop && ./build/test_chop
./build/render_demo_chop          # audio/chop_demo.wav, 20 с
```

## Почему это отдельный движок, а не режим Sample

| | Sample | CHOP |
|---|---|---|
| что играет | весь one-shot с начала | один слайс из середины |
| выбор материала | `table` (источник) | `table` (луп) + слайс по ноте или `p[0]` |
| высота | всегда по ноте | в режиме Slices — **не** зависит от ноты |
| конец | хвост сэмпла | конец куска: обрыв с окном 5 мс |
| что нового в DSP | MIP-уровни | детектор атак + окно в шкале исходника |

## Контент: лупы с известной истиной

Лупов в поставке нет (как и сэмплов — всё синтезируется), поэтому каждый луп
собирается из событий: `loopgen::addKick/addSnare/addHat/addVox/addStab`.
Генератор **знает**, где поставил удар (`truth`), а слайсы ищет отдельный
детектор по готовому сигналу — поэтому детектор проверяется сравнением с
истиной, а не сам с собой.

| луп | длина | события | слайсов найдено |
|---|---|---|---|
| Break 96 | 2.80 с | кик 1 и 3.5, снейр 2 и 4, хэты 16-ми (96 BPM) | 5 = 5 ударов |
| Vox Chop | 2.92 с | 8 формантных слогов (220…330 Гц, шаг 0.34 с) | 9 = 8 + служебный «остаток» |
| Dub Stabs | 3.97 с | 6 стабов (пила с закрывающимся фильтром) | 7 = 6 + «остаток» |

Всего 3.6 МБ с MIP-уровнями (пять октав вверх), строится за 78 мс на старте.

## Детектор атак (`detectSlices`)

```
огибающая   = пиковый детектор с удержанием (мгновенный рост, спад 30 мс)
порог       = max(0.30 · maxEnv, 2 · медиана)      при sens = 0.5
              (доля = 0.50 − 0.40 · sens)
гистерезис  = сброс «взведён» только ниже 0.40 · порога
мин. шаг    = 50 мс
откат       = 3 мс назад, чтобы не срезать атаку
```

Замеры (`test_chop`, блок 1):

| проверка | результат |
|---|---|
| все удары найдены | **19 из 19** |
| худшее отклонение границы от истинного удара | **5.0 мс** |
| ложных слайсов | **0** |
| sens 0.05 → 5 слайсов, sens 1.0 → 13 | порог управляем, при 1.0 режутся и хэты |

**Что пришлось переделать.** Первая версия огибающей была однополюсником
1.5 мс по модулю — и давала **по два слайса на кик**: у синуса 55 Гц модуль
проваливается между полупериодами каждые 9 мс, гистерезис сбрасывался и
следующий полупериод снова перебивал порог (лишние слайсы ровно через 0.116 с
после каждого кика, 8 слайсов вместо 5). Пиковый детектор с удержанием убрал
пульсации полностью.

Вторая ошибка: порог 6 % от максимума находил в брейке **16 слайсов** — каждый
хэт считался ударом, хотя он тише кика в 3–4 раза. Порог 30 % от максимума при
sens 0.5 даёт ровно 5.

## Параметры движка

| параметр | смысл | диапазон |
|---|---|---|
| `p[0]` | 0 — слайс выбирается нотой (Slices); > 0.02 — слайс выбирается параметром, нота транспонирует (Chromatic) | 0…1 |
| `p[1]` | длина: какая доля слайса играется | 5…100 % |
| `p[2]` | повторы (stutter) | 1…4 |
| `p[3]` | > 0.5 — обратный ход | 0/1 |
| `table` | номер лупа | 0…2 |

## Демо `audio/chop_demo.wav`

20 с, четыре фразы (RMS по двухсекундным окнам, провалов нет):

| время | что играет | RMS |
|---|---|---|
| 0–5 с | раскладка: 10 ударов брейка по нотам 45+ | 0.059 / 0.057 / 0.058 |
| 5–10 с | транспонирование одного удара по 16 нотам | 0.058 / 0.038 / 0.054 |
| 10–15 с | повторы: `p[2]` 0 → 1 | 0.036 / 0.038 / 0.070 |
| 15–20 с | реверс каждого третьего + второй луп (вокальные слоги) | 0.071 / 0.042 |

Итог: пик 0.890, RMS 0.054, DC 1·10⁻⁵, клипов 0.

## Где движок в инструменте

* `EngineType::Chop = 8`, создаётся в `makeEngine()`, контент — `EngineBank::loops`.
* В плагине — 9-й вариант списка `TYPE` у каждого слота (число параметров
  не изменилось: choice остаётся одним параметром, 284).
* Фабричный патч **«Chop Break»** (7-й): CHOP по нотам 45+ плюс тихий Karplus
  для тела; `p.gain = 3.45`, замеренная громкость в общей калибровке
  (RMS 0.0908 против 0.0963…0.0970 у остальных, разброс 0.6 дБ, пик 0.627).

## Что не сделано

* Резка по нулевым переходам и «snap to grid» (сетка BPM) — детектор только
  по атакам.
* Автоматическая нормализация каждого слайса по RMS: сейчас громкость слайса
  такая, какая записана (разброс 3.2 дБ на пробном лупе, на реальных ударах
  больше — кик громче хэта).
* Загрузка внешних лупов: банк процедурный, файлового импорта нет.
