# Движок 07 — Resynth

Ресинтез: сэмпл не проигрывается, а «перечитывается» как набор партиалов.
Время и высота становятся независимыми.

```
make build/test_resynth && ./build/test_resynth
```

## Данные

| что | значение |
|---|---|
| анализ | кадры по 10 мс, окно Ханна 2048, до 32 пиков на кадр |
| уточнение частоты | парабола по лог-магнитуде трёх бинов |
| объём кадров | 8 источников, **406 КБ** (исходные сэмплы — 6.0 МБ) |
| хранение | `freq[32] + amp[32]` на кадр, слоты фиксированы (пик-трекинг) |

## Замеры

| проверка | результат |
|---|---|
| алиасинг (стационарный пробник), ноты 45/57/69 | −81.0 / −77.1 / −73.6 дБ |
| партиалы выше Найквиста, ноты 69/81/93 | −63.0 / −59.2 / −53.1 дБ |
| DC | 0.80·10⁻³ |
| RMS / разброс по источникам | 0.188 / 0.0 дБ |
| stretch 0.25 → 4.0 | длина 1.00 → 8.50 → 16.01 с, центроид 1748 / 1748 / 1747 Гц |
| pitch −7 / 0 / +7 полутонов | длительность 2.36 / 2.36 / 2.36 с |
| CPU | 21.7 % ядра на 16 голосов = 1.35 %/голос (32 синуса) |

Офлайн-демо: `audio/resynth_demo.wav` — 20 с: пэд со stretch 4 → быстрое арпеджио
со stretch 0.25 → голос с drift. Пик 0.890, RMS 0.119.

## Три бага, найденные замерами

### 1. Фаза в радианах для табличного синуса

`fastSin()` в проекте принимает фазу **в оборотах** (0…1), а я подавал радианы
(0…2π). Результат: партиал 110 Гц звучал на 691 Гц, весь спектр уезжал
в негармонический — метрика показывала **−17.8 дБ «алиасинга»** у абсолютно
чистого синтеза. После исправления: −73.6 дБ.

### 2. Пик-трекинг вместо сортировки по частоте

Первая версия брала 32 самых громких пика и сортировала их по частоте.
Состав партиалов в соседних кадрах разный, поэтому индекс `j` начинал
соответствовать другому партиалу: частота прыгала на сотни герц, синтез
«чирикал». Энергия размазывалась по спектру — снова «алиасинг» −15 дБ.

Решение: траектории. Слот `j` занимает пик, ближайший по частоте (±6 %) к
предыдущему кадру; умерший партиал остаётся в слоте с `amp = 0` и гаснет
сглаживанием. Новые партиалы занимают свободные слоты.

### 3. Метрика алиасинга на музыкальном сэмпле неприменима

Ресинтез обновляет партиалы раз в 10 мс. У записи с атакой и затуханием
амплитуды партиалов быстро меняются, каждая гармоника «размазывается» на ±50 Гц,
и метрика «энергия вне k·f0» считает это размытие алиасингом (−17 дБ).
Поэтому стенд гоняет движок на **стационарном пробнике** (`buildProbeShot()`),
где амплитуды постоянны. То же решение, что у Granular, — но здесь подменяется
контент, а не метрика.

## Почему время и высота независимы

- **Stretch**: `framePos` растёт медленнее (или быстрее) — это меняет только
  скорость продвижения по кадрам. Частоты партиалов берутся из кадра и
  интерполируются, поэтому тембр не зависит от времени: центроид 1748 Гц
  при растяжении 0.25…4.0.
- **Pitch**: множитель всех частот, число кадров и скорость их смены не меняются:
  длительность 2.36 с при −7/0/+7 полутонах.

## Что осталось за рамками

- Нет шумового (стохастического) остатка: ударные и шипящие согласные
  ресинтезируются «стерильно» — в Terrain Resynth это отдельный слой.
- Нет фазового выравнивания между кадрами (фазы интегрируются свободно) —
  для унисона с исходником нужен анализ фаз.
- 32 партиала — потолок для CPU; в реальном инструменте их 64–128 с
  адаптивным распределением по громкости.
