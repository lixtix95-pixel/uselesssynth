# OROGEN — играбельная демка «в духе Terrain»

Один файл `index.html`, без зависимостей и внешних ресурсов. Открывается в браузере, звучит сразу после нажатия **START AUDIO** (браузер требует жест пользователя для запуска Web Audio).

Локальный сервер уже запущен: `http://<preview>:8000`

## Что внутри технически

- **Аудио:** один `ScriptProcessorNode` (512 сэмплов) = полифонический движок (14 голосов), далее нативная цепь Web Audio.
- **Голос:** до 8 генераторов, SVF-фильтр (TPT, 2 каскада), amp-огибающая + env2, мод-матрица с block-rate обновлением.
- **Движки:** вейвтейбл с интерполяцией кадров и позиции; грануляр (2 грейна на слот, Hann-окно, spray); FM (2 оператора + доп. модулятор + feedback); модальный (3 резонансные моды с индивидуальным распадом); сэмплер (питч-шифт по нотам); гармонический; **Resynth** (анализ → банк партиалов → ресинтез по Чебышёву); **Organics** (зоны + корпусный резонатор + транзиент + drift).
- **Подробный разбор каждого движка** — в [ENGINES.md](ENGINES.md).
- **Эффекты:** модульная схема «in → wet/dry → out», реордер пересобирает граф, IR реверба генерируется процедурно.
- **CPU:** ~3 % ядра на 4 голосах с 2–3 активными слотами (замер в Node на этом же DSP-коде).

### Известные ограничения демки
1. Вейвтейблы без band-limited мипмапов → возможен алиасинг на верхних октавах (в VST-версии решается таблицами по октавам + 2× оверсэмплинг).
2. `ScriptProcessorNode` устарел и работает в главном потоке; в плагине будет свой DSP-поток.
3. Нет патчер-графа, CHOP, Tape Deck, MPE, реального сэмпл-контента.

## Следующий шаг: перенос в VST3 (JUCE)

Демка — это фактически референс поведения. Ядро переносится почти один-в-один:

| В демке | В JUCE |
|---|---|
| `voices[]`, `triggerVoice()` | `juce::Synthesiser` + свой `SynthesiserVoice` (или MPE-совместимый `MPESynthesiser`) |
| `node.onaudioprocess` | `AudioProcessor::processBlock` |
| `S` (объект патча) | `juce::AudioProcessorValueTreeState` + `juce::ValueTree` для графа |
| `S.mods` | своя мод-матрица: control-rate обновление с `SmoothedValue` |
| `FXN` модули | классы `FxProcessor` с общим интерфейсом + топосорт графа |
| `WAVETABLES` | контент-бандл: `.wt` файлы, мипмапы по октавам, mmap-загрузка |
| `PRESETS` | JSON/ValueTree пресеты + версионирование формата |
| HTML-кнопки | `Component`-ы: `juce::Slider` (rotary), `ComboBox`, `TabbedComponent` |
| `undoStack` | `juce::UndoManager` + `UndoableAction` на каждое действие |

Порядок работ, который я предлагаю:
1. **Каркас плагина** (CMake + JUCE, параметры, состояние, сборка VST3/AU/Standalone).
2. **DSP-ядро:** перенос движков и фильтра, band-limited таблицы, тест CPU и алиасинга.
3. **Мод-матрица + карточки** (Arp/Shaper/Robin/Glitch).
4. **Патчер-граф** как в Terrain (ноды + кабели + топосорт).
5. **FX-рэк из 16 эффектов.**
6. **Контент-пайплайн:** WAV→wavetable (FFT), метаданные, банк пресетов, установщики.
