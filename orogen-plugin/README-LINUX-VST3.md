# OROGEN VST3 — Linux x86-64

Это собранный Linux-бандл VST3 (Release, JUCE 8.0.15), а не Windows-плагин.
Ревизия от 29.10.2026: 9 движков, 298 автоматизируемых параметров, интерфейс
1280×800. Сборка проверена через JUCE VST3-хост; в конкретной DAW не проверялась.

## Установка

Распакуйте `OROGEN.vst3` целиком в `~/.vst3/` и просканируйте плагины в DAW:

```bash
mkdir -p ~/.vst3
cp -a OROGEN.vst3 ~/.vst3/
```

Сборке нужны Linux x86-64, GLIBC не ниже 2.38 и GLIBCXX не ниже 3.4.32,
а также стандартные графические библиотеки Linux/JUCE. На более старых системах
соберите из исходников на целевой машине. Проверить версию GLIBC: `ldd --version`.

Исходники той же ревизии находятся в `OROGEN-vst3-vs2022.zip`: несмотря на имя,
там обычные кроссплатформенные исходники CMake, DSP и JUCE-обёртки. Сам архив не
содержит собранного Windows VST3; его скрипт для Visual Studio 2022 не проверялся
в этой Linux-среде. Лицензии и авторство сторонних библиотек: `LICENSE`,
`NOTICE.md` и `licenses/` в этом архиве. JUCE 8 распространяется по AGPL-3.0
либо отдельной коммерческой лицензии; тексты и условия компонентов см. там же.

Примечание по совместимости: 294 прежних параметра сохранили ID и порядок, ещё
четыре добавлены в конец. Старый проект с Plate pre-delay выше 100 мс будет
звучать иначе: теперь исполняется сохранённое значение до 200 мс, тогда как
раньше DSP ошибочно ограничивал его 100 мс.
