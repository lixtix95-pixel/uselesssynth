# OROGEN VST3 — Linux x86-64

Это собранный Linux-бандл VST3 (Release, JUCE 8.0.15), а не Windows-плагин.
Ревизия: 9 движков, 890 автоматизируемых параметров, GUI 1280×800.
Откройте **FX RACK** или **X**; выберите тип и нажмите **+ ADD**. Выберите
строку и используйте **UP / DOWN** для перестановки аудиотракта, **REMOVE**
для удаления, **ON/OFF** для обхода. Перетаскивание мышью не реализовано.
INIT содержит 13 выключенных стадий. До 16 экземпляров всего, до 4 одного
типа; новые копии имеют отдельные параметры и DSP. Порядок и настройки
сохраняются в DAW state, JSON и банке. Старые 376 ID не переименованы и не
переставлены; старые состояния без позиций получают прежний порядок.
Базовая сухая задержка ROBIN 1024 отсчёта остаётся даже после удаления #1;
каждая дополнительная копия ROBIN добавляет 1024, включая OFF. Дополнительную
задержку могут вносить SPECTRE и прошивочный CHORUS; она сообщается хосту.
При подготовке новой копии во время воспроизведения она кратко может отсутствовать;
состав/порядок переключается с fade 6+6 мс. Состояние удалённых/выключенных
эффектов может сохраняться и возобновляться. Мастер DC-блокер/лимитер активны.
У Granular есть `PARAMS → SLOT → A…H → Grain Reverse`, 0…1. Отдельной загрузки
аудио в GUI нет; доступны восемь фабричных источников.

Проверки предыдущей ревизии до перестраиваемой цепи: 22 DSP-набора, **514/514**; расширения FX
дополнительно **61/61** под ASan/UBSan. Полный `test_plugin` с native-окном
и XTEST — **240/240**, отдельная страница FX — **23/23**, внешний JUCE
VST3-хост с XTEST — **66/66**. Хост загрузил реальную сессию предыдущего VST3:
один проверенный MIDI-сценарий дал побайтно одинаковый звук. Все 154 FX-контрола
доступны; на трёх размерах окна 13 переключателей и выбор эффектов проверены
мышью (39/39). На карточках A–H клик по ON/LEVEL/TUNE выбирает соответствующий
слот, не прерывая действие контрола; тест peer 72/72 на трёх размерах окна.
Синтетическими XTEST-кликами через настоящее меню выбраны все 9 типов на каждом
из 8 слотов: 72/72, с проверкой параметров и изоляции. 36/36 пар аудиорендеров
разных типов различимы.
Метры слотов затухают и атомарно публикуются; GUI-подписи PARAMS увеличены,
расцветка монохромна. Анимация LFO перерисовывает только необходимые зоны,
при wrap S&H — всю кривую. В конкретной DAW сборка не проверялась.

При ненулевом Spread Granular теперь использует независимые случайные потоки
для разных нот и слотов; старые проекты с таким Spread могут зазвучать иначе,
в том числе при Reverse 0 или 100%. Жесты дисплея, FX-чипов, модуляции, ADSR
и VectorPad передают хосту начало и завершение изменения параметров.

В Granular исправлены асимметрия огибающей прямых/обратных зёрен и оценка
неполного хвоста; в одном фабричном сценарии пики Choir/Vox снижены без
лимитера (**1.364268 → 0.919871 / 1.306653 → 0.881589**). Это меняет уровни
затронутых зёрен. Сырые пики Granular для некоторых других настроек всё ещё
могут превышать 1.0 во float; ограничение не скрывается лимитированием WAV.

## Установка

Распакуйте `OROGEN.vst3` целиком в `~/.vst3/` и просканируйте плагины в DAW:

```bash
mkdir -p ~/.vst3
cp -a OROGEN.vst3 ~/.vst3/
```

Сборке нужны Linux x86-64, GLIBC не ниже 2.38 и GLIBCXX не ниже 3.4.32,
а также стандартные графические библиотеки Linux/JUCE. На более старых системах
соберите из исходников на целевой машине. Проверить версию GLIBC: `ldd --version`.

Исходники той же ревизии находятся в `OROGEN-vst3-vs2022.zip`: несмотря на имя,
там обычные кроссплатформенные исходники CMake, DSP и JUCE-обёртки. Сам архив не
содержит собранного Windows VST3; его скрипт для Visual Studio 2022 не проверялся
в этой Linux-среде. Лицензии и авторство сторонних библиотек: `LICENSE`,
`NOTICE.md` и `licenses/` в этом архиве. JUCE 8 распространяется по AGPL-3.0
либо отдельной коммерческой лицензии; тексты и условия компонентов см. там же.
В предоставленном репозитории MonoHuice 0.9.15 корневой LICENSE не обнаружен:
разрешение на дальнейшее распространение его собственного кода следует
уточнить у правообладателя; некоммерческое использование само по себе его
не предоставляет.

Примечание по совместимости: все 306 ID перед обновлением FX сохранили ID и
порядок; новые 70 добавлены в конец (первые 338 ID также не переставлены). Отсутствующий Reverse в старом JSON или
состоянии сессии сбрасывается в 0. При вероятности Reverse между 0 и 1 старые
патчи могут звучать иначе: теперь каждая пара нота/слот имеет свой поток
направлений. У общих фабричных источников Choir и Vox исправлено вибрато;
старые проекты с ними могут изменить звук в Granular, Sample, Organics и
Resynth. Остальные источники в проверенном банке 48 кГц не изменились.
Старый проект с Plate pre-delay выше 100 мс будет
звучать иначе: теперь исполняется сохранённое значение до 200 мс, тогда как
раньше DSP ошибочно ограничивал его 100 мс. Исправления Granular, MIP и петли
Organics также могут изменить звучание старых проектов при тех же параметрах.
Исправление разрыва лимитера влияет на сигнал выше прежнего порога 0.98; ниже
него ограничитель прозрачен. Delay Feedback выше 0.92 теперь использует всё
сохранённое значение до 0.95; Detune Granular стал работать, а удержанные тихие
голоса и Pan/Width теперь реагируют на автоматизацию, поэтому прежние проекты
с такими настройками могут звучать иначе. Detune и Pitch фиксируются для каждого
зерна при его запуске: автоматизация слышна на следующих зёрнах, а не мгновенно
на активных. Нормировка Granular в динамичных участках, поведение Delay при
Mix 0 и сглаживание Time/Mix/Feedback также изменяют звук прежних проектов.
Исправление дробной позиции Granular меняет высоту тех зёрен, которые прежде
расстраивались при чтении поздних участков источника. Постоянная задержка
ROBIN — 1024 отсчёта, включая случай mix=0.
