# OROGEN VST3 — Linux x86-64

Это собранный Linux-бандл VST3 (Release, JUCE 8.0.15), а не Windows-плагин.
Ревизия от 31.10.2026: 9 движков, 306 автоматизируемых параметров, интерфейс
1280×800. У Granular добавлена вероятность обратного чтения каждого нового
зерна: `PARAMS → SLOT → A…H → Grain Reverse`, 0…1. Отдельной загрузки аудио
в GUI нет; доступны восемь фабричных источников. Сохранены 298 прежних ID и
порядок, 8 новых находятся в конце и по умолчанию равны 0.

14 DSP-наборов: 370/370; `test_plugin` с native-окном: 217/217; внешний JUCE
VST3-хост: 54/54, включая реальную сессию предыдущего VST3, автоматизацию на
удержанной ноте, независимые потоки двух слотов, два сценария Choir и 6
открытий/выгрузок. Метры слотов затухают и атомарно публикуются; GUI-подписи
PARAMS увеличены, расцветка монохромна. В конкретной DAW сборка не проверялась.
Сырые пики Granular для некоторых источников могут превышать 1.0 во float;
ограничение не скрывается лимитированием WAV.

## Установка

Распакуйте `OROGEN.vst3` целиком в `~/.vst3/` и просканируйте плагины в DAW:

```bash
mkdir -p ~/.vst3
cp -a OROGEN.vst3 ~/.vst3/
```

Сборке нужны Linux x86-64, GLIBC не ниже 2.38 и GLIBCXX не ниже 3.4.32,
а также стандартные графические библиотеки Linux/JUCE. На более старых системах
соберите из исходников на целевой машине. Проверить версию GLIBC: `ldd --version`.

Исходники той же ревизии находятся в `OROGEN-vst3-vs2022.zip`: несмотря на имя,
там обычные кроссплатформенные исходники CMake, DSP и JUCE-обёртки. Сам архив не
содержит собранного Windows VST3; его скрипт для Visual Studio 2022 не проверялся
в этой Linux-среде. Лицензии и авторство сторонних библиотек: `LICENSE`,
`NOTICE.md` и `licenses/` в этом архиве. JUCE 8 распространяется по AGPL-3.0
либо отдельной коммерческой лицензии; тексты и условия компонентов см. там же.

Примечание по совместимости: все 298 параметров прошлой версии сохранили ID и
порядок; новые восемь добавлены в конец. Отсутствующий Reverse в старом JSON или
состоянии сессии сбрасывается в 0. При вероятности Reverse между 0 и 1 старые
патчи могут звучать иначе: теперь каждая пара нота/слот имеет свой поток
направлений. Старый проект с Plate pre-delay выше 100 мс будет
звучать иначе: теперь исполняется сохранённое значение до 200 мс, тогда как
раньше DSP ошибочно ограничивал его 100 мс. Исправления Granular, MIP и петли
Organics также могут изменить звучание старых проектов при тех же параметрах.
Исправление разрыва лимитера влияет на сигнал выше прежнего порога 0.98; ниже
него ограничитель прозрачен. Delay Feedback выше 0.92 теперь использует всё
сохранённое значение до 0.95; Detune Granular стал работать, а удержанные тихие
голоса и Pan/Width теперь реагируют на автоматизацию, поэтому прежние проекты
с такими настройками могут звучать иначе. Detune и Pitch фиксируются для каждого
зерна при его запуске: автоматизация слышна на следующих зёрнах, а не мгновенно
на активных. Нормировка Granular в динамичных участках, поведение Delay при
Mix 0 и сглаживание Time/Mix/Feedback также изменяют звук прежних проектов.
Исправление дробной позиции Granular меняет высоту тех зёрен, которые прежде
расстраивались при чтении поздних участков источника. Постоянная задержка
ROBIN — 1024 отсчёта, включая случай mix=0.
